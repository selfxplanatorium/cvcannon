# Templates

Each subfolder is a reusable design bundle containing:

- `cv.html`
- `cover-letter.html`

The included `default` bundle is a starting point. Copy it to a lowercase, hyphenated name to save another design:

```bash
cp -R BASE/TEMPLATES/default BASE/TEMPLATES/editorial
```

Fonts, colors, spacing, sections, icons, and layout may be changed. Keep candidate data out of saved templates and preserve one-page A4 output with selectable text. Use static local or embedded fonts and resources.

Run `make templates` to list complete bundles.
