# Candidate profile

`master-cv.html` is the authoritative CV used to create every application.

On first use, provide information in whichever form is easiest:

- place an existing CV in this folder;
- place a PDF, DOCX, HTML, Markdown, or text file with career information here; or
- paste the information directly into the conversation with the agent.

The agent uses that material to create `master-cv.html`. Source files can keep their original names.

A portrait is optional. When used, save it as `portrait.webp` (preferred), `portrait.png`, `portrait.jpg`, or `portrait.jpeg`; otherwise the master CV omits the portrait element. WebP renders the same and keeps the finished PDF smaller; `make portrait-convert` converts a PNG or JPEG portrait in place. If no portrait is present, the agent asks whether you intended one and remembers the answer.

See the [first-time setup](../docs/SETUP.md) for the complete process.
